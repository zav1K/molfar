# Відео для меню

Кинь сюди `menu_loop.ogv` — і меню само почне його крутити замість
нерухомої картинки. Нема файлу — лишається картинка. Нічого в коді
міняти не треба (`scripts/menu_backdrop.gd`).

**Godot програє тільки Ogg Theora.** Ні mp4, ні webm. Конвертація:

```
ffmpeg -i вхід.mp4 -c:v libtheora -q:v 8 -an menu_loop.ogv
```

`-an` прибирає звукову доріжку: звуком меню завідує `AudioDirector`,
і доріжка всередині відео грала б повз нього й повз налаштування
гучності.

## Якщо в циклі видно стрибок

Найнадійніший прийом — програти вперед і назад. Кінець другої половини
дорівнює початку першої, тож шва не існує за побудовою:

```
ffmpeg -i вхід.mp4 -filter_complex "[0:v]split[a][b];[b]reverse[r];[a][r]concat=n=2:v=1" \
       -c:v libtheora -q:v 8 -an menu_loop.ogv
```

Для хмар, туману й гойдання гілок це майже непомітно. Для диму гірше —
він на секунду «втягується» назад.

## Що просити в генератора

Камера **нерухома**: ні наїзду, ні панорами. Саме дрейф камери робить
шов видимим — якщо кадр повільно від'їжджає, перша й остання секунди не
зійдуться ніколи.

Ніщо не входить і не виходить із кадру: пролітаючий птах чи сніжинка
руйнують цикл гарантовано.

Бери найкоротше, що дає генератор — 3–5 секунд. Що довше, то сильніше
картинка відпливає від початкового кадру.
